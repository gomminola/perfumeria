# Gomminola Perfumería

Sitio estático de catálogo para Gomminola. El catálogo de perfumes y relojes, el carrito y el asistente están integrados en `index.html` y los scripts de `assets/`.

## Publicación

El repositorio está preparado para GitHub Pages mediante GitHub Actions. En GitHub, abre **Settings → Pages** y selecciona **GitHub Actions** como fuente si aún no está habilitada. Cada envío a `main` genera una nueva versión del sitio.
